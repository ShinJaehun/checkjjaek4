# 2026년 11월 베타 사용자 피드백 결정 기록

2026년 11월 베타 피드백에 대해 사용자와 합의한 최종 결정이다.
현재 동작과 후속 개발 후보를 구분하며, 후속 후보의 상세 구현 정책은 별도 작업에서 확정한다.

| 피드백 | 결정 |
| --- | --- |
| 책짹 소개·사용 매뉴얼·튜토리얼 | 별도 개발하지 않는다. 기존 포트폴리오와 GitHub 자료를 유지한다. |
| 짹 모음 탭 | 프로필에서 기존 짹을 확인할 수 있으므로 별도 탭을 추가하지 않는다. |
| 캐릭터 보상·꾸미기 | 지금 구현하지 않는다. 향후 책짹 교실에서 제한적으로 검증하고, 효과를 확인한 뒤 그룹 → 전체 SNS 확대를 검토한다. |
| 책 첨부 시 서재 등록 | 최우선 기능 개선 후보. 기존 짹 첨부 목록의 ‘서재에도 추가’ 동작(현재 UI 문구: `책장에 담기`)을 중복 개발하지 않는다. 개선 대상은 짹에 첨부할 책을 검색·선택하는 화면에서도 서재 등록 버튼을 함께 제공하는 것이다. 기존 `BookshelfEntry` 중복 방지와 책장 선택 정책을 유지하며, 상세 구현은 후속 작업에서 확정한다. |
| 온라인 서점·도서관 검색 | 후속 검토 대상으로 남기며 지금 구현하지 않는다. |
| 모바일 책 검색의 2영역 UI | 현재 의도된 설계이므로 유지한다. 확인되지 않은 버그로 기록하지 않는다. |
| 짹 사진 첨부 | 책 검색·선택 화면 개선 다음의 주요 기능 개발 후보. 기존 Active Storage와 OCI Object Storage 재사용을 검토한다. 사진 수·크기·형식·공개 범위·삭제 정책은 구현 전에 결정한다. |

일반 책 찾기의 검색 결과에는 이미 서재 등록 기능이 있다. 이번 개선 후보는 짹 첨부용 검색·선택 화면에 관한 것이다.
책 첨부만으로 서재에 자동 등록하지 않는 기존 정책은 유지한다.

현재 통합 짹·첨부·서재 독립성의 기준은 [통합 짹 명세](../specs/unified_jjaeks.md),
기존 검색·서재 등록 흐름은 [현재 시스템 문서](../architecture/current_system.md#7-책-검색-화면-book_search)를 따른다.
이 기록은 후속 기능의 구현 완료나 사진 첨부의 세부 정책 확정을 의미하지 않는다.
