# 개인 독서 노트

## 데이터와 권한

- 사용자·책별 `UserBook`에 `BookNote`를 여러 개 저장한다. 제목은 선택이며 본문은 Action Text에 저장한다. 일반 텍스트 기준 10,000자까지 허용하고, 비어 있거나 서식만 있는 본문은 거부한다. 작성·수정 시각을 보존한다.
- 본인만 노트를 조회할 수 있다. 책장 공개 범위, 책친구, global admin 권한은 노트 조회 범위를 넓히지 않는다. 목록에는 본인 기록만 조회하며 단건과 변경 요청도 서버에서 권한을 검사한다.
- 현재 `BookshelfEntry`가 있을 때 본인이 노트를 작성·수정·삭제할 수 있다. 책을 꺼내면 읽기만 가능하며, 다시 담으면 기존 노트와 편집 권한을 복원한다. `UserBook` 삭제 또는 계정 탈퇴 시 노트와 리치 텍스트를 함께 정리한다.
- 노트 변경은 `BookActivity`를 생성하지 않는다. 짹과의 변환이나 게시를 제공하지 않으며, 홈 피드·검색·프로필 타임라인·알림·타인 서재에 노트를 노출하지 않는다.

## 화면과 확인 기준

- 책 상세의 [나의 독서 탭](bookshelf_ui.md#책-상세와-개인-독서-관리)에서 본인의 노트를 최신 작성순으로 확인한다. 배치된 책의 `노트 작성` 버튼과 편집 권한이 있는 노트의 `노트 수정` 버튼은 제목이 `독서 노트`인 모달을 연다. 선택한 노트에서 본문을 읽거나 권한에 따라 확인 후 삭제할 수 있다. 책장에서 꺼낸 책은 책 상세의 읽기 링크를 유지한다. 타인 서재·프로필에서 진입한 책 상세와 동아리 문맥에는 노트 영역을 표시하지 않는다.
- 책 아이콘과 `독서 노트` 제목은 목록 바깥에 한 번만 표시한다. 본인 서재에서는 상위 탐색의 `독서 노트` 링크에, 책 상세에서는 책짹 목록과 같은 스타일의 섹션 제목에 책 아이콘을 표시한다.
- 본인 서재와 책 상세의 노트 목록은 작성·열람 화면의 미색 종이 스타일을 적용한 공통 카드를 사용한다. 카드에는 노트 제목, 작성 시각, 본문 미리보기와 책 정보를 표시한다. 카드 전체가 노트 상세로 연결되며, 하단 책 정보는 작은 표지와 책 제목, 값이 있는 저자·출판사를 항목명 없이 한 번씩 표시한다. 표지의 기존 대체 표시를 사용하며, 제목이 비어 있으면 목록과 상세에 `제목 없는 노트`를 표시한다.
- 미리보기는 Action Text의 일반 텍스트를 줄임표 포함 최대 120자로 표시한다. 두 목록의 작성 시각은 `time.formats.short`를 사용한다. 두 목록의 정렬·페이지네이션·복귀 경로와 책장에서 꺼낸 책의 노트를 유지한다.
- 노트 작성·수정 모달과 상세는 미색 배경, 얇은 테두리와 그림자, 왼쪽 여백선, 읽기 편한 제목·본문 글꼴을 공유한다. 가로줄은 종이 하단의 빈 여백에 표시해 Trix 서식과 줄바꿈에 따른 본문 줄 높이를 보존한다.
- 공책 상단에는 연결된 책 제목과 저자(값이 있는 경우), 현지화한 날짜를 표시한다. 작성 모달에는 오늘 날짜, 수정 모달과 상세에는 최초 작성일을 표시한다. 상세의 상단 책 정보 영역 전체가 책 상세로 연결되며, 값이 있는 표지와 출판사도 함께 표시한다.
- 작성·수정 모달은 `독서 노트` 제목 아래 왼쪽에 작은 책 표지 또는 기존 대체 썸네일을 링크 없이 표시한다. 오른쪽에는 책 제목을 최대 두 줄, 저자를 값이 있는 경우 한 줄로 표시하고 초과분은 줄임표로 처리한다. 작성일은 별도 줄에 표시하며 기존 구분선 아래에 제목과 본문 입력을 둔다.
- 노트 상세는 제목과 Action Text 본문 전체를 표시한다. 편집 권한이 있으면 본문 아래에 수정·삭제 버튼을 표시한다. 돌아가기는 진입 위치에 따라 서재의 독서 노트 탭이나 책 상세의 나의 독서 탭으로 연결한다.
- Trix 기본 서식과 이미지 추가 버튼을 지원한다. 파일 선택·클립보드 이미지 붙여넣기·파일 드롭은 같은 인증 업로드 흐름을 사용한다. 이미지는 커서 위치에 삽입하고 업로드 진행 상태를 표시한다. 업로드 중에는 저장을 막고, 실패한 이미지는 편집기에서 제거해 오류를 표시한다.
- 업로드가 끝난 이미지는 본문에서 미리보고 위치를 바꾸거나 제거할 수 있다. 상세는 삽입 위치와 이미지 비율을 유지하며 화면 너비에 맞춰 표시한다. 목록 미리보기는 본문 텍스트만 사용한다. 본문에 이미지가 있어도 비어 있지 않은 텍스트가 필요하다.
- 모달은 작은 화면에서도 입력과 툴바를 사용할 수 있어야 한다. 수정된 내용의 닫기에는 확인을 제공한다. 검증 실패 시 입력을 복원해 모달에서 오류를 표시하고, 저장은 제출할 때 실행한다.

## 이미지 저장 기반

- 본인 `UserBook`에 현재 책장 배치가 있을 때 활성 계정만 이미지를 업로드할 수 있다. JPEG·PNG·WebP의 실제 형식과 디코딩 가능 여부를 검사한다. 원본은 5MB, 입력 해상도는 4천만 픽셀까지 허용한다. 긴 변을 1600px 이내로 줄이고 metadata를 제거한 WebP 한 장을 저장한다.
- 회원별 한도는 최적화 파일 100MB다. 현재 연결, 임시, 업로드 중, 삭제 대기 파일을 합산한다. 회원 잠금 안에서 최적화 크기를 예약하고 실제 파일 삭제가 성공한 뒤 차감한다. 일일 횟수 제한은 두지 않는다.
- `POST /books/:book_id/book_note_images`는 multipart의 `image` 한 장을 받아 `201`과 내부 `id`, 인증 조회 `url`, 임시 만료 시각 `expires_at`을 반환한다. 입력·한도 오류는 `422`와 오류 코드·번역 메시지, 저장소 장애는 `503`을 반환한다.
- `GET /books/:book_id/book_note_images/:id`는 현재 소유자에게만 파일을 비공개 스트리밍한다. 임시는 업로드 완료 후 24시간 동안 조회할 수 있다. 노트에 연결된 이미지는 현재 노트와 같은 `UserBook`에 속해야 하며 책에서 꺼낸 뒤에도 읽을 수 있다. 권한이 없거나 이미지가 없으면 `404`를 반환한다. 저장소 URL과 Blob 서명 ID를 응답에 포함하지 않는다.
- 본문은 서버가 검증한 `BookNoteImage` 식별자를 Action Text에 삽입 순서대로 보관한다. 같은 `UserBook`의 만료 전 임시 이미지와 현재 노트에 이미 연결된 이미지에 한해 최대 4장까지 저장한다. 타인의 이미지, 다른 노트에 연결된 이미지, 삭제·만료된 참조, 임의 Blob 서명 ID, 외부 이미지·직접 삽입한 이미지나 미디어를 거부한다. 렌더링과 편집 복원에서는 조회 경로를 앱에서 다시 생성한다.
- 본문 저장과 `attach_to!`·`discard_from!`은 같은 DB 트랜잭션에서 처리한다. 저장에 실패하면 기존 본문과 이미지 연결을 되돌리고 작성 중인 텍스트와 유효한 이미지 배치를 복원한다. 이미지가 빠진 수정은 저장 성공 시 삭제 대기로 전환한다. 취소하거나 사용하지 않은 새 업로드는 임시 상태로 남는다.
- 노트 또는 `UserBook`이 삭제되면 연결 정보가 해제되어 기존 주소에서 조회할 수 없다. 만료된 임시 이미지, 중단된 업로드, 삭제 대기 및 부모가 삭제된 이미지는 정기 작업에서 삭제한다. 저장소 삭제가 실패하면 객체 키와 용량 예약을 유지해 재시도한다. [운영 기준](../ops/book_note_images.md)을 따른다.
