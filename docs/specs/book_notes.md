# 개인 독서 노트

## 데이터와 권한

- 사용자·책별 `UserBook`에 `BookNote`를 여러 개 저장한다. 제목은 선택이며 본문은 Action Text에 저장한다. 일반 텍스트 기준 10,000자까지 허용하고, 비어 있거나 서식만 있는 본문은 거부한다. 작성·수정 시각을 보존한다.
- 본인만 노트를 조회할 수 있다. 책장 공개 범위, 책친구, global admin 권한은 노트 조회 범위를 넓히지 않는다. 목록에는 본인 기록만 조회하며 단건과 변경 요청도 서버에서 권한을 검사한다.
- 현재 `BookshelfEntry`가 있을 때 본인이 노트를 작성·수정·삭제할 수 있다. 책을 꺼내면 읽기만 가능하며, 다시 담으면 기존 노트와 편집 권한을 복원한다. `UserBook` 삭제 또는 계정 탈퇴 시 노트와 리치 텍스트를 함께 정리한다.
- 노트 변경은 `BookActivity`를 생성하지 않는다. 짹과의 변환이나 게시를 제공하지 않으며, 홈 피드·검색·프로필 타임라인·알림·타인 서재에 노트를 노출하지 않는다.

## 화면과 확인 기준

- 책 상세의 [나의 독서 탭](bookshelf_ui.md#책-상세와-개인-독서-관리)에서 본인의 노트를 최신 작성순으로 확인한다. 배치된 책에서는 작성 모달을 열 수 있고, 선택한 노트에서 본문 읽기와 수정 모달 또는 확인 후 삭제를 제공한다. 책장에서 꺼낸 책은 책 상세의 읽기 링크를 유지한다. 타인 서재·프로필에서 진입한 책 상세와 동아리 문맥에는 노트 영역을 표시하지 않는다.
- 본인 서재와 책 상세의 노트 목록은 동일한 카드를 사용한다. 독서 노트 아이콘·라벨·작성 시각, 노트 제목, 본문 미리보기, 책 정보 순으로 표시한다. 카드 전체가 노트 상세로 연결되며, 하단 책 정보는 작은 표지와 책 제목, 값이 있는 저자·출판사를 항목명 없이 한 번씩 표시한다. 표지와 노트 제목의 기존 대체 표시를 재사용한다.
- 미리보기는 Action Text의 일반 텍스트를 줄임표 포함 최대 120자로 표시한다. 두 목록과 노트 상세의 작성 시각은 `time.formats.short`를 사용한다. 책 상세에서는 책짹 목록과 같은 스타일의 섹션 제목 아래에 노트 카드를 배치한다. 두 목록의 정렬·페이지네이션·복귀 경로와 책장에서 꺼낸 책의 노트를 유지한다.
- 노트 상세는 목록과 같은 순서와 카드 스타일을 사용하며 Action Text 본문 전체를 표시한다. 본문 아래 구분선 다음의 책 정보 영역 전체가 책 상세로 연결된다. 편집 권한이 있으면 그 아래에 수정·삭제 버튼을 표시한다. 돌아가기는 진입 위치에 따라 서재의 독서 노트 탭이나 책 상세의 나의 독서 탭으로 연결한다.
- Trix 기본 서식을 지원한다. 에디터에서 첨부를 차단하며, 서버도 Action Text 첨부와 HTML에 직접 삽입된 이미지·미디어를 거부한다. 본문 표시는 Action Text의 안전한 렌더링을 사용한다.
- 모달은 작은 화면에서도 입력과 툴바를 사용할 수 있어야 한다. 수정된 내용의 닫기에는 확인을 제공한다. 검증 실패 시 입력을 복원해 모달에서 오류를 표시하고, 저장은 제출할 때 실행한다.
