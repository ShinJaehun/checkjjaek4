# C10 로그인 중 비밀번호 변경

## 범위와 정책

- 로그인한 사용자는 `/account/settings`에서 현재 비밀번호, 새 비밀번호,
  새 비밀번호 확인을 입력해 자기 비밀번호만 변경한다.
- `PATCH /account/settings/password`는 프로필·관계 설정 저장과 분리하며,
  비밀번호 관련 세 필드만 허용한다.
- 현재 비밀번호 검증과 새 비밀번호 확인·길이 검증은 Devise를 사용한다.
  빈 새 비밀번호와 누락된 새 비밀번호 확인도 거부한다.
- 실패하면 기존 비밀번호와 로그인 상태를 유지하고 설정 화면에 오류를 표시한다.
  비밀번호 입력값은 다시 표시하지 않으며 기존 로그 필터링을 유지한다.
- 성공하면 현재 세션에서 로그아웃하고 로그인 페이지로 이동해
  새 비밀번호로 로그인하도록 안내한다. HTML과 Turbo 요청에 같은 결과를 제공한다.
- 이메일 변경(C11), 추가 이메일 발송, DB migration은 포함하지 않는다.
  기존 비밀번호 재설정과 프로필·관계·이미지 설정 흐름을 유지한다.

## Acceptance Criteria

- 정상 변경 후 기존 비밀번호로 로그인할 수 없고 새 비밀번호로 로그인할 수 있다.
- 현재 비밀번호 오류·누락, 새 비밀번호 누락·길이 오류, 확인 불일치·누락은
  저장하지 않고 화면에서 확인할 수 있다.
- 미로그인 변경 요청은 로그인 페이지로 이동하며 비밀번호를 변경하지 않는다.
- 변경 요청으로 다른 계정이나 프로필·관계 설정을 수정할 수 없다.
