# 로그인 상태 유지

## 정책

- 로그인 화면의 비밀번호와 로그인 버튼 사이에 `로그인 상태 유지` / `Remember me` 체크박스를 표시한다. 기본값은 체크 해제다.
- 기존 Devise `:rememberable`, `user[remember_me]`와 `remember_created_at`을 사용한다. 자체 토큰이나 DB 컬럼을 추가하지 않는다.
- 체크하고 정상 로그인하면 브라우저를 다시 열었을 때 유지 쿠키로 최대 30일 동안 인증을 복원한다.
  기존 Devise의 기간 자동 연장 비활성화를 유지하며 일반 세션 만료 정책은 변경하지 않는다.
- 체크하지 않거나 값을 보내지 않으면 새 장기 로그인 쿠키를 발급하지 않는다.
- 로그아웃 시 `expire_all_remember_me_on_sign_out = true`에 따라 유지 토큰을 무효화한다. 보관한 이전 쿠키로도 복원할 수 없다.
- 탈퇴 계정의 `active_for_authentication?` 제한과 기존 정지 계정 제한을 유지한다.
- Devise·Rails의 기존 Secure, HttpOnly, SameSite 처리를 재사용하며 쿠키 보안을 낮추지 않는다.

## Acceptance Criteria

- ko/en 로그인 화면에서 체크박스의 이름·라벨과 체크 해제 기본값을 확인할 수 있다.
- 체크 여부에 따라 장기 쿠키 발급이 구분되며 일반 세션 쿠키 없이도 유효한 유지 쿠키로 인증을 복원한다.
- 30일이 지난 쿠키와 로그아웃으로 무효화된 쿠키는 서버에서 거부한다.
- 로그인 유지 쿠키와 `remember_me=1`로도 탈퇴 계정의 인증 제한을 우회할 수 없다.
