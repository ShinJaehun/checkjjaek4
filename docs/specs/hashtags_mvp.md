# 해시태그 MVP (D01)

## 입력과 저장

- 일반 짹·책짹·추천짹과 동아리의 같은 게시물 유형의 기존 `content`에서 `#` 뒤에 이어지는 한글·영문·숫자·밑줄을 태그로 추출한다. 공백·하이픈·문장부호에서 끝나며 `#` 단독은 태그가 아니다. 별도 입력 필드와 본문 길이 변경은 없다.
- 태그 이름은 Unicode NFC 정규화와 영문 대소문자 통합을 거쳐 저장한다. 본문 원문은 보존하고 같은 게시물의 중복 태그는 연결 하나로 저장한다. 추출과 화면 링크는 같은 문법을 사용한다.
- 성공한 작성·본문 수정 뒤 연결을 동기화한다. 본문에서 사라진 태그는 연결을 제거하며 게시물 삭제와 tombstone 때도 제거한다. 과거 게시물은 운영 환경에서 자동 실행하지 않는 멱등적 `bin/rails jjaek_tags:backfill` 작업으로 처리한다.

## 표시와 검색

- 공통 짹 본문에서 실제 `#태그` 부분을 강조한 검색 링크로 표시한다. 본문과 링크 텍스트는 HTML escape하며 기존 줄바꿈·공백을 유지한다. 카드 하단에 별도 태그 목록을 추가하지 않는다.
- `/search`의 기존 `q` 부분 문자열 검색과 사용자·짹·책짹·동아리 탭에 추천짹 탭을 추가한다. `tag` 모드는 저장된 정확한 태그 연결로 짹·책짹·추천짹만 찾으며, 전체 미리보기 5건과 개별 탭의 30·50·100건 페이지네이션 및 최신순 정렬을 재사용한다. `#우정`으로 `#우정의힘`을 찾지 않는다.
- `/search`는 문자열과 태그에 하나의 `q` 입력창을 쓴다. 일반 검색 결과에는 `독서`, 태그 검색 결과에는 `#독서`처럼 현재 검색어를 표시하며 게시물의 기존 `tag` 링크도 같은 화면을 연다. 기존 태그 문법에 맞는 단일 `#태그`를 입력하면 정규화한 `tag` URL로 이동하고 `q`는 함께 검색하지 않는다. 짹·책짹 유형과 표시 개수는 유지하고 사용자·동아리 유형은 전체로 바꾸며 페이지는 첫 페이지로 돌린다. 일반 검색에서 태그를 입력한 경우 범위는 전체가 기본이다. 단일 태그 형식이 아닌 입력은 기존 `q` 검색으로 처리한다.
- 태그 결과는 `JjaekPolicy::SearchScope`에서 시작해 hidden/deleted와 현재 접근할 수 없는 개인·동아리 글 및 다시짹을 제외한다. 운영 관리자 전용 우회나 권한 없는 결과 건수 노출은 없다.

## 클릭한 화면의 문맥

- 동아리 상세의 태그 링크는 해당 동아리, 사용자 프로필의 태그 링크는 해당 사용자, 홈·일반 글 상세·발견 및 기타 화면의 태그 링크는 전체 범위를 기본으로 연다. 태그 검색 필터에는 실제 동아리 이름을 넣은 “{동아리 이름}에서”, 실제 사용자 이름을 넣은 “{사용자 이름}의 짹에서”와 “모든 짹에서”를 표시한다. 자기 프로필에도 실제 이름을 사용한다.
- 검색 유형과 태그 범위 필터는 PC에서 좌우 한 줄로, 좁은 화면에서 위아래로 배치하고 긴 이름은 줄바꿈해 가로 넘침을 막는다. 일반 문자열 검색에는 태그 범위 필터가 없다.
- 검색 결과 안에서 새 태그를 누르면 현재 유효한 범위·유형·표시 개수를 유지하고 페이지는 첫 페이지로 돌린다. 태그 검색에는 범위와 전체를 전환하는 링크를 제공하며 전환 시 태그·유형·표시 개수를 보존하고 페이지는 첫 페이지로 돌린다. 상세 복귀는 태그·범위·대상 ID·유형·표시 개수·현재 페이지를 보존한다.
- 동아리·사용자 범위의 태그 검색 입력창에 다른 단일 `#태그`를 넣으면 검증된 현재 범위를 유지한다. 일반 문자열로 바꾸면 태그 전용 범위와 대상 ID를 URL에서 제거하고 일반 검색으로 이동한다. 두 모드 모두 입력 변경 시 페이지는 첫 페이지로 돌리고 유효한 표시 개수는 유지한다.
- `scope`, `group_id`, `user_id`는 요청에서 신뢰하지 않는다. 동아리 범위는 기존 Group 읽기 정책, 사용자 범위는 기존 프로필 접근 정책을 확인하고 잘못된 조합 또는 접근 불가 대상은 같은 404로 처리한다. 범위 필터는 권한을 넓히지 않는다.

## 범위 밖

- A11 무한 스크롤, 태그 자동완성, 검색 엔진 교체, Gem 추가는 포함하지 않는다.

## Acceptance Criteria

- 한글·영문·숫자·밑줄, 종료 문자, 중복, NFC와 대소문자 통합이 추출·저장·링크에서 일치한다.
- 작성·수정·삭제·tombstone 및 재실행 가능한 backfill이 연결을 정확히 유지한다.
- 정확한 태그 검색과 화면 문맥별 범위, 권한 경계, 페이지·상세 복귀가 동작하고 기존 `q` 검색을 유지한다.
- 하나의 `q` 입력창이 일반 검색어와 `#태그`를 표시·제출하며, 태그 검색 중 새 태그는 범위를 유지하고 일반 검색어는 범위를 제거한다.
- 본문과 링크는 안전하게 escape되며 읽기 전용 검색 카드의 작성 문맥과 동작을 유지한다.
