# 발견 페이지 MVP — 작업 1

## 목적과 범위

로그인 사용자가 홈 피드와 별도로 공개된 책짹, 짹, 서재, 동아리를 우연히 발견할 수 있는 `/discover` 화면을 제공한다. 기존 상세 화면으로 이동하며, 추천 알고리즘·개인화·새로고침·별도 탐색 화면은 포함하지 않는다.

## 후보와 표시

- 주요 책은 접근 가능한 개인 영역의 전체 공개 원본 책짹이 있는 책 중 무작위로 1권 선정한다. 작성자의 책장 공개 여부는 후보 조건이 아니다. 책 표지·제목·저자와 해당 책짹 최대 3개를 표시한다.
- 우연히 발견한 짹은 다른 사용자의 접근 가능한 개인 영역 전체 공개 일반 원본 짹 중 최대 3개를 표시한다. 작성자, 실제 본문 미리보기, 원문 링크를 제공한다.
- 두 짹 영역은 가능한 한 서로 다른 작성자의 글을 먼저 선정하고, 후보가 모자라면 같은 작성자의 다른 글로 채운다.
- 짹 후보는 `JjaekPolicy::Scope`에 개인 영역(`group_id: nil`), `public_jjaek`, 숨김·삭제 아님, 원본(`quoted_jjaek_id: nil`, `quoted_source_deleted_at: nil`) 조건을 추가한다. `book_id`의 유무로 책짹과 일반 짹을 구분한다. 다시짹과 삭제 원문 관련 잔존 레코드는 추천하지 않는다.
- 추천 서재는 자신을 제외한 사용자 중 전체 공개 책장에 책이 있는 사용자 1명을 선정한다. 전체 공개 책장에 속한 책만 수량과 표지 최대 4권에 반영한다. 책친구 한정·비공개 책장 정보는 사용하지 않는다.
- 추천 동아리는 `GroupPolicy::Scope`를 거친 active 공개·승인 동아리 중 운영 정지되지 않은 1개를 선정한다. 미가입 동아리를 우선한다. 이름, 소개, 유형, 기존 상세 기준 회원 수와 관리자·일반 회원 아바타를 표시한다.
- 추천 동아리의 최근 짹·책짹은 `GroupPolicy#read_jjaeks?`가 허용할 때 `JjaekPolicy::GroupContentScope`에서 숨김·삭제 및 열람할 수 없는 인용 원문을 제외한 최신 최대 3개를 표시한다(`created_at DESC, id DESC`). 공개 동아리와 승인 동아리 활동 회원에게 적용한다. 승인 동아리 비회원에게는 게시물 대신 가입 승인 안내를 표시한다. 볼 수 있는 게시물이 없으면 빈 상태를 표시한다.
- 후보가 적으면 있는 만큼만 보여주고, 각 영역에 후보가 없으면 빈 상태를 표시한다.

## 권한과 화면

- 기존 Pundit 정책은 변경하지 않는다. 정책 scope 결과에 발견 화면 전용 공개 후보 조건을 추가하며, 상세 링크는 기존 권한 경계를 따른다.
- 작성자의 비공개 책장 정보와 비공개 서재 항목, 비공개·초대 전용 동아리 및 승인 동아리 비회원에게 내부 게시물을 노출하지 않는다.
- 상단은 책짹·일반 짹을 크게 배치한 데스크톱 2열, 모바일 1열이다. 중간에 추천 서재, 하단에 추천 동아리를 둔다. 타이포그래피·여백·얇은 구분선으로 신문형 편집 레이아웃을 만든다.
- 가상의 기사나 요약 문구, 동작하지 않는 새로고침 버튼을 표시하지 않는다. 새 UI 문자열은 한국어와 영어 locale에 둔다.

## 검증

- 로그인 진입, 네 영역, 기존 상세 링크, 후보 부족과 빈 데이터 상태를 request spec으로 확인한다.
- 비공개·책친구 한정·숨김·삭제·다시짹 제외와 공개 책장만의 수량·표지를 확인한다. 동아리 게시물은 권한별 노출, 숨김·삭제 및 접근 불가 인용 원문 제외를 확인한다.
- pending/inactive/운영 정지/비공개 동아리 제외와 미가입 우선을 확인한다.
