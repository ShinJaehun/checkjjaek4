# 공통 버튼 스타일

- 버튼과 버튼 형태의 링크는 `app/assets/tailwind/application.css`의 `.ui-button`과 하나의 색상 variant를 사용한다. View에는 너비·여백·반응형 표시 등 배치 클래스만 추가한다.
- 기본 터치 영역은 최소 44×44px이다. 모서리는 rounded-xl, 글꼴은 text-sm/font-semibold, 아이콘과 문구 간격은 gap-2로 관리한다.
- primary는 딥그린 `#276749`로 작성·저장·검색·승인 등 주요 실행에 사용한다. secondary는 기존 중립색으로 보조 실행·닫기·이동에 사용한다.
- danger는 기존 빨강 계열로 삭제·탈퇴·종료·이용 제한 등 파괴적 동작에 사용한다. warning은 기존 앰버 계열로 운영 정지·숨김·복구 등 운영 조치와 주의가 필요한 실행에 사용한다. 기존 동작·권한·확인 절차는 유지한다.
- 색상은 CSS 사용자 정의 속성으로 관리한다. 모든 버튼은 그림자·눌림 이동 없는 평면형으로 표시하며 hover는 배경색만 자연스럽게 변경한다. active 배경색과 focus-visible outline을 유지하고 active를 hover 뒤에 선언한다. 크기·패딩·모서리·글꼴과 기존 색상은 유지한다.
- native disabled와 aria-disabled의 시각 상태는 투명도를 낮추고 전환 효과를 제거한다. aria-disabled는 동작 차단을 대신하지 않는다. 기존 서버 권한과 실제 disabled 처리를 유지한다.
- reduced-motion 환경에서는 전환 애니메이션을 생략한다.
- 선택 카드·칩은 평면형 `.ui-choice`로 통일한다. 최소 높이 44px, 흰 배경·얇은 중립 테두리와 공통 hover·focus-visible·disabled 상태를 사용하며 그림자·눌림 이동·선택 ring은 사용하지 않는다. 입력의 실제 체크 표시와 강조 테두리·은은한 배경으로 선택을 구분한다.
- 독서 상태는 `.ui-choice-status`의 stone 계열, 스티커는 `.ui-choice-sticker`의 amber 계열, 게시 위치·공개 범위 카드는 `.ui-choice-card`의 amber 계열을 사용한다. 책장 선택과 동아리 관리자 후보 선택은 기본 stone 표현을 사용한다. 기존 helper는 이 공통 클래스만 반환하고 읽기 전용 배지 표현은 유지한다.
- 설정 폼의 기본 체크박스, 책장 색상 swatch, 서재 이동의 카드 위 체크박스는 고유 형태를 유지한다. swatch는 44px 터치 영역과 키보드 포커스를 제공하고 이동 체크박스의 그림자는 제거한다. 관리자 필터의 기존 select는 변경하지 않는다.
- 탭·배지·작은 아이콘 버튼·피드의 텍스트 액션과 일반 텍스트 링크는 기존 표현을 유지한다. 별도 버튼 helper/partial은 추가하지 않는다.
- 프로필의 기존 버튼 helper는 권한·라벨·경로 선택 책임을 유지하고 공통 클래스만 반환한다.
- 모바일 내비게이션·작성 폼·관계 버튼·서재 하단 action bar·동아리 관리·관리자 테이블에서 높이 증가와 줄바꿈을 브라우저로 확인한다. 스타일 교체만으로 Turbo·Stimulus·확인창·접근성 속성을 변경하지 않는다.
